# Очередь принудительного включения синхронов

## Назначение

Приватная команда администратора `/force` принимает ID или ссылки на турниры и сохраняет их до первого успешно опубликованного опроса, в котором турнир доступен хотя бы для одного стандартного слота. Команда недоступна в группах и не-администраторам.

## Поведение

- `/force` открывает диалог, `/force id1,id2` обрабатывает список сразу; `/cancel` отменяет активный приватный диалог.
- Все ID проверяются через CHGK API перед записью. Ошибка разбора или отсутствующий турнир отклоняют весь ввод.
- Очередь уникальна по `TournamentId` и упорядочивается по времени постановки.
- При `/poll` форсированные турниры, доступные в 13:00 или 15:30 UTC+5, обходят обычные фильтры и идут перед обычными кандидатами. При 10+ таких турнирах опрос не публикуется.
- Записи удаляются вместе с сохранением `PollSession` только после удачной публикации Telegram poll. Ошибки публикации или недоступность турнира очередь не меняют.

## Границы и безопасность

Application содержит сценарий постановки в очередь и порты хранилища/CHGK; Infrastructure реализует EF-репозиторий и миграцию; Worker лишь авторизует команду, ведёт in-memory состояние диалога и показывает результат. В логи не попадает полный пользовательский ввод, а названия турниров HTML-экранируются перед отправкой в Telegram.
