# Общий PostgreSQL на Orange Pi

## Решение

Production-версия AlmatyLISPollingBot не запускает собственный PostgreSQL-контейнер. Контейнер бота подключается к `snakefrogcalendarbot-postgres` через внешнюю Docker-сеть `snakefrogcalendarbot_default`, созданную Compose-проектом SnakeFrogCalendarBot.

`DATABASE__NAME`, `DATABASE__USERNAME` и `DATABASE__PASSWORD` остаются отдельными настройками LIS-бота и должны указывать на учётные данные существующего PostgreSQL. Это сохраняет способ конфигурации из требований и позволяет не передавать строку подключения либо секреты в Compose-файле.

## Альтернативы

- Оставить отдельный контейнер PostgreSQL: расходует память Orange Pi и создаёт второй экземпляр без необходимости.
- Подключаться через опубликованный порт хоста: требует открытого порта и специальной маршрутизации из контейнера.
- Использовать общую Docker-сеть: выбранный вариант, потому что трафик остаётся внутри Docker и использует DNS-имя контейнера.

## Безопасность и проверка

Compose не содержит паролей и не публикует дополнительный порт PostgreSQL. Скрипт redeploy до сборки проверяет наличие внешней сети и сообщает, что сначала требуется запустить SnakeFrogCalendarBot. Проверка `docker compose config`, unit-тесты расчёта времени и полный набор .NET-тестов подтверждают конфигурацию и доменное правило.
