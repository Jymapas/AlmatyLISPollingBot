# ID турнира в `/options`

Строка с ID добавляется в общий `TournamentListFormatter`: `<b>ID:</b> <code>{id}</code>`. Telegram отображает значение в моноширинном формате и позволяет скопировать его нажатием. Существующая авторизация и поток обработки `/options` не меняются; регрессионный тест проверяет HTML-тег `code` и точное значение ID.
