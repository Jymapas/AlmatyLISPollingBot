# Основная стоимость в `/options`

## Понимание задачи

- `/options` должен быть компактнее и показывать только основную стоимость турнира.
- Сообщение перед опросом и `/excluded` продолжают показывать все выбранные категории стоимости.
- Выбор валюты и пересчёт в тенге должны остаться одинаковыми для всех списков.

## Допущения

Основной считается первая категория в уже выбранной валюте. Валюта выбирается существующим порядком `KZT`, затем `RUB`, `USD`, затем первая оставшаяся; смысл поля `reason` не интерпретируется дополнительно.

## Дизайн

`TournamentListFormatter` получает обязательный `TournamentPaymentCategoriesDisplayMode`. Для `PrimaryOnly` он оставляет первую категорию `SelectPaymentCategories`, поэтому сохраняет текущий приоритет валют и формат первой строки «Стоимость». `ListTournamentOptionsService.ExecuteAsync` передаёт этот режим только для `/options`; `StartPollService` и `ExecuteExcludedAsync` передают `All`.

Изменение не затрагивает состав кандидатов, пагинацию, API-запросы, хранение, Telegram poll и обработку курсов. Для не-KZT основной цены сохраняется пересчёт в тенге и флаг предупреждения о недоступном курсе.

## Безопасность и ошибки

Режим валидируется на входе formatter. Новых внешних запросов, пользовательского ввода или чувствительного логирования не появляется.

## Тестирование

Тесты formatter фиксируют вывод всех цен в полном режиме и одной основной цены в compact-режиме. Use case тесты подтверждают полный список перед poll и единственную цену в `/options`. Полный набор тестов, форматирование и аудит NuGet входят в done-критерий.

## Журнал решений

| Решение | Альтернативы | Причина |
| --- | --- | --- |
| Первая категория выбранной валюты | Поиск `reason = «по умолчанию»` | Сохраняет текущую семантику первой цены без догадок о неструктурированном тексте. |
| Явный режим formatter | Обрезать данные в `/options` use case | Общие правила валюты и курса остаются в одном месте. |
| Ограничить только `/options` | Убрать цены во всех списках | Соответствует точной области feature request. |
